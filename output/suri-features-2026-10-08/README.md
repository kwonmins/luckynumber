# 수리 기능 확장 개발용 APK · 2026-10-08

- 파일: `suri-features-tarot-noads-debug.apk`
- 앱 ID: `com.example.unum` · Android 8.0 이상 · 개발용 Debug 서명
- 탭: 홈 / 운세 / 혜택 / 프리미엄 / 마이
- 상담은 기존 프리미엄운세를 의미합니다. 프리미엄 운세노트 보관함은 마이에서도 열 수 있습니다.

추가한 기능: 운세 모아보기, 내일·지정일 운세, 월간 흐름, 최근 5일 흐름, 시간대별 운세, 수비학, 행운 아이템, 출석 포인트, 타로와 최근 90일 타로 기록.

타로는 주요 카드 22장·정방향으로 구성했습니다. 종합 / 연애 / 일·학업 / 금전 / 마음 중 한 분야를 선택하고 하루 한 장을 뽑습니다. 같은 날 분야를 바꿔도 다시 뽑지 않습니다. 한국시간 자정에 새 기회가 열립니다.

로그인한 계정은 서버의 한국 날짜와 계정별 고유 키로 하루 제한을 적용합니다. 게스트는 기기 안에 결과를 저장합니다. 서버 함수와 소유자별 읽기 정책을 적용했고, 같은 날 재뽑기·중복 출석·비인증 접근 검증을 통과했습니다.

광고: 실제 AdMob 앱·보상형 광고 ID 설정을 사용하지만 `AdMobConfig.ADS_ENABLED=false`로 광고 요청과 표시를 중지했습니다. 개발 중에는 타로 상세 해석을 광고 없이 읽습니다. 배너·네이티브 광고 단위 ID는 아직 입력되지 않았으며 다음 설정 키로 연결할 수 있습니다.

```properties
admob.banner.ad.unit.id=
admob.native.ad.unit.id=
```

광고 적립과 포인트 사용처는 준비 중으로 표시합니다. 이 APK에서는 광고 적립을 실행하지 않습니다.

검증: 단위 테스트 13개, Pixel_6 Android 14 에뮬레이터 테스트 2개 통과. 에뮬레이터 테스트는 재방문 시 같은 타로 유지, 동시 요청·재생성 후 결과 유지, 중복 출석 차단, 광고 표시 비활성화를 확인했습니다.

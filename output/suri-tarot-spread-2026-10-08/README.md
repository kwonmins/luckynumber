# 수리 타로 스프레드 개발용 APK

`suri-tarot-spread-noads-debug.apk`

- 수리 캐릭터 앞면 22장, 공통 뒷면, 메뉴 그림 적용
- 카드 22장을 부채꼴로 펼쳐 표시
- 좌우 드래그나 터치는 카드 고르기만 수행하며 하루 제한을 사용하지 않음
- 고른 카드를 위로 64dp 이상 끌었다 놓거나, ‘선택한 카드 뽑기’ 버튼을 누르면 뽑기 확정
- 화살표 버튼과 접근성 동작으로도 카드 선택 가능
- 저장된 결과가 도착하면 뒷면에서 앞면으로 뒤집기 애니메이션
- 당일 재방문에는 저장된 앞면과 해석을 바로 표시
- 하루 한 번 및 한국시간 자정 초기화 규칙 유지
- 실제 광고 ID 설정 유지, 광고 SDK의 로드·표시는 계속 꺼짐 (`ADS_ENABLED=false`)

카드 선택 위치는 화면 상의 선택 경험이며 실제 결과는 기존의 22장 무작위 뽑기와 저장 경로를 사용합니다. 분야를 바꾸거나 여러 번 누르는 것으로 당일 결과가 바뀌지 않습니다.

검증: Debug APK 빌드 성공, JVM 단위 테스트 13개와 Pixel 6 / Android 14 기기 테스트 3개 통과. 카드 고르기는 결과를 저장하지 않고, 위로 끌어 뽑기 확정은 한 번만 호출되며, 당일 재방문에는 동일한 저장 결과가 유지되는 것을 확인했습니다.

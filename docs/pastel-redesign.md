# 파스텔 수리운세 UI/UX 개편

이 문서는 이전 디자인 기록이다. 2026-10-06에 반영한 구조와 화면 기준은 [architecture.md](architecture.md)를 참고한다.

## 기준

사용자가 제공한 크림·연보라 모바일 화면, 달·벚꽃·운세 아이콘 시안과 승인한 수리 파스텔 스프라이트만을 디자인 기준으로 사용했다.
별도의 UI 레퍼런스나 외부 디자인 템플릿은 사용하지 않았다.

## 화면 흐름

- 시작: 달 장식, 새 수리, 게스트 시작 및 기존 카카오 로그인.
- 홈: 오늘의 운세 배너 → 무료 운세 6개 → 프리미엄 배너 → 수리 안내 → 오늘 메시지 → 보관함.
- 무료: 생년월일 미입력 시 입력 화면으로 이동한다. 입력 후 분야 카드를 누르면 해당 메시지를 연다.
- 프리미엄: 일반/연애 탭 → 분야 선택 → 질문 입력 및 추천 질문 → 질문 확인 → 기존 이용 절차 → 생성 결과.
- 일반: 학업, 재물, 시험을 먼저 표시한다. 기존 추가 상담 분야는 ‘다른 분야’에서 유지한다. 시험은 학업 상담의 하위 주제로 연결한다.
- 연애: 짝사랑, 커플, 재회에 따라 기존 관계 상태를 설정한다. 상대 생년월일 입력을 유지한다.
- 결과: 밝은 종이 카드와 달·벚꽃 헤더, 단락별 본문. 책자 결과의 스크랩·PDF 공유·글자 크기 설정을 유지한다.
- 하단: 홈, 운세, 스크랩, 프리미엄, 마이. 기존 앱 경로를 유지하고 얇은 선 아이콘을 사용한다.

## 구현 위치

- `ui/theme`: 크림 배경, 연보라 행동 색상, 남보라 글자, 살구·분홍 포인트.
- `ui/components/PastelArt.kt`: 달·산·벚꽃 배너, 운세 일러스트, 수리 atlas 셀 렌더링.
- `presentation/home/HomeScreen.kt`: 새 홈 구성과 분야 메시지.
- `presentation/premium/PastelPremiumForm.kt`: 일반/연애 선택과 질문 입력.
- `presentation/onboarding/OnboardingScreen.kt`: 새 시작 화면.
- `presentation/result/ResultScreen.kt`: 무료 결과 헤더.
- `presentation/reader/ReaderScreen.kt`: 단락 단위 결과 읽기.
- `ui/components/CommonComponents.kt`: 공통 버튼, 배경, 카드, 하단 메뉴.

## 자산

`drawable-nodpi/suri_pastel_atlas.png`는 승인된 4열 × 3행 투명 포즈 시트 원본이다.
런타임에 셀 단위로 렌더링하며 원본 파일은 편집하지 않는다.
각 포즈는 표정·동작 상태이고 연속 애니메이션 프레임이 아니다.
배너와 운세 아이콘은 참고 시안의 형태와 색을 바탕으로 Compose Canvas로 그려 해상도에 대응한다.

## 기능 범위

데이터 계산, 인증, 광고 보상, 상담 생성, 저장소, 서버 및 API 키 구성은 유지한다.
무료 건강·행운 카드는 현재 무료 결과의 주의·행동 문구를 활용한다. 전용 건강 예측 데이터셋을 새로 생성하지 않는다.
공통 테마를 통해 입력·설정·결제·보관함에도 동일한 색과 버튼 스타일을 적용한다.

## 검증 기록

- Pixel 6 에뮬레이터에서 시작 → 게스트 홈 → 프리미엄 이동을 확인했다.
- 일반/연애 탭과 학업·짝사랑·커플·재회 카드 표시를 확인했다.
- 생년월일 확인 → 무료 결과 생성 → 추천 질문 선택 → 질문 확인 단계까지 확인했다.
- 결과 화면에서 발견한 키워드 대비 문제를 수정했다.
- 시작·홈·일반·연애·질문·무료 결과 캡처는 `design_previews/pastel_redesign`에 저장했다.
- 단위 테스트 8개와 Debug APK 빌드를 실행했다.
- 실제 카카오 로그인, 광고 보상, 결제, 유료 AI 호출 및 PDF 내보내기는 이번 화면 검증에서 실행하지 않았다.

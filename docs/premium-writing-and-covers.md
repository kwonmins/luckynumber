# 프리미엄 해설과 달빛 표지

공통 해설 규칙은 `FortuneWritingRules.kt`, 분야별 장 구성은 `PersonalPrompt.kt`, 관계별 구성은 `CompatibilityPrompt.kt`에서 관리합니다. 기존 모델, 숫자 계산, JSON 필드와 페이지 ID는 유지합니다.

- 사용자가 밝힌 상황과 질문을 먼저 읽고 답합니다. 없는 사건이나 상대의 속마음을 만들어 붙이지 않습니다.
- 핵심수는 0 창의력, 1 추진력, 2 관찰력, 3 언변력, 4 기초·원리와 안정, 5 모험·적응, 6 책임·돌봄, 7 분석, 8 사교성, 9 완성도입니다. 보조 숫자로 핵심 성격을 대체하지 않습니다.
- 성격을 구체적인 고민 장면과 연결하고 원인을 설명합니다. 행동·선택에는 대상을 밝힙니다.
- 장별 역할은 고민의 핵심, 강점, 어려움의 이유, 기회의 조건, 선택별 차이, 행동, 상징적 참고, 마무리입니다. 행동은 1~2개만 제시합니다.
- 글자 수를 채우기 위한 추상적 비유나 모든 숫자에 같은 조언을 반복하지 않습니다. 전체 해설은 2,500자 이내로 요청합니다.
- 고민과 성향은 JSON 데이터로 이스케이프해서 전달합니다. 기존 저장 결과는 다시 생성하지 않습니다.
- 정상 응답의 월별 이유는 그대로 보존합니다. 모델이 월을 잘못 돌려주면 기존 계산값으로 교정하고 상징적 참고 설명을 씁니다.

변경 확인은 10개 숫자 × 9개 분야, 빈 질문, 줄바꿈·따옴표가 있는 고민, 세 관계 상태, 응답 파싱과 월별 이유 보존을 포함합니다. 고정 응답 테스트는 형식과 저장 동작을 검증하며 실제 AI 문장 품질을 측정하지는 않습니다. 후속 품질 검토에는 같은 고민에 대해 핵심수가 다른 결과, 같은 핵심수에 고민이 다른 결과를 비교하고 구체성·문맥·중복·사실성·질문에 대한 답변을 살펴봅니다.

달빛 표지의 색과 상징은 `MoonlightCoverStyle.kt`에서 관리합니다. 분야명을 먼저 해석하여 학업/진로, 건강/나 자신, 사업/재물처럼 예전 테마를 공유했던 분야도 구별합니다. `MoonlightBookPainter`가 책장 카드, 펼친 표지, 결과 화면과 PDF에 같은 문양을 그립니다. 작은 카드에는 긴 부제를 생략하고 접근성 설명에는 실제 책 제목을 포함합니다.

총운·나 자신·진로·인간관계를 포함한 분야 아이콘과 운세 메뉴는 앱에서 직접 그리는 파스텔 삽화를 사용합니다. 타로는 기존 수리 카드 그림과 하루 한 번 제한을 유지합니다. 광고 로드와 표시는 계속 비활성화합니다.
